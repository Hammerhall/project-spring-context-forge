# Срез демобазы Postgres Pro

Данные этого каталога — настоящие данные демобазы «Авиаперевозки» компании Postgres
Professional, взятые из репозитория её генератора:

* https://github.com/postgrespro/demodb
* коммит `f317597ecc8b0ec7e1eec1554519e7a6bc23aea4`

Лицензия — MIT, её текст и уведомление об авторских правах — рядом, в `LICENSE-demodb.txt`.

Что взято — без правок значений:

* `airports.tsv` — 15 аэропортов из `airports_data.dat`: код IATA, название, город,
  код страны, страна, долгота, широта, часовой пояс. Коды: SVO, VKO, DME, LED, KZN, AER, SVX, OVB, KJA, DEL, KTM, PEK, HND, JFK, AKL;
* `airplanes.tsv` — 10 моделей из `airplanes_data.dat`: код, модель, дальность, км,
  крейсерская скорость, км/ч, в работе ли (`t` / `f`);
* `seats.tsv` — 1741 мест из `seats.dat`: код модели, номер места, класс обслуживания.

Изменён только вид: из имён на двух языках взято русское, точка «долгота, широта»
разделена на два столбца, служебный столбец `traffic` не взят.
